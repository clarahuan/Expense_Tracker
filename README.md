# 轻记

适配 iPhone 的个人记账网页。Python 标准库 + 原生 HTML/CSS/JavaScript，无需安装 Python 依赖。

## 启动

双击 `start.bat`，或在本目录运行 `python server.py`。电脑打开 http://localhost:8000 。

iPhone 和电脑连接同一个 Wi-Fi，在 Safari 输入终端显示的局域网地址（例如 http://192.168.1.10:8000）。电脑需保持开机和服务运行。如 Windows 提示防火墙权限，只允许专用网络。若无法访问，请检查是否为访客 Wi-Fi、网络隔离或防火墙阻止 Python。换端口：`python server.py --port 8080`。

## 功能

- 手动支出记账：金额、八种分类、时间、商户、备注。
- 单笔微信/支付宝截图 OCR：提取金额与时间、根据关键词建议分类。先核对再保存；识别不是保证正确的支付接口。
- 月份选择、分类筛选、分类环图、每日柱状图、日均消费、月度对比。
- 疑似重复提醒、删除账单、按月 CSV 导出。
- 数据存放在 `data/expenses.db`，手机与电脑共用账本。备份时停止服务后复制该文件；恢复时用备份替换原文件。

## 截图识别

使用 Tesseract.js 5.1.1，通过 jsDelivr 按需加载；语言模型和计算组件首次使用也需联网下载。截图在浏览器内识别，不发送给本工具服务器，也不保存。网络不可用或 CDN 不通时手动记账仍可使用。推荐 PNG/JPG 的单笔账单详情页；HEIC 的解码取决于浏览器。低清晰度、复杂排版可能识别错误，未识别时间时暂填当前时间并提示。退款、收入和转账需要人工区分，本版只管理支出。

## 使用范围

当前是可信家庭局域网内的单账本原型，没有账号和访问密码，同一网络内能访问端口的人也能读写账本。不要映射到公网。离开家随时访问需要后续部署 HTTPS、账号认证与备份；手机仅在家中网络使用是当前版本的边界。它不能监听微信或支付宝付款，也不能在付款后自动弹窗。当前不支持账单编辑，可删除后重新添加；图表无演示账单，展示真实记录。

## 文件

- `server.py`：HTTP API、SQLite 数据存储与输入校验。
- `web/index.html`、`web/style.css`、`web/app.js`：页面、响应式样式、交互与 OCR。
- `start.bat`：Windows 启动入口。

后续可先增加编辑和身份认证，再部署远程服务，最后探索 iOS 快捷指令入口。账本数据已在 `.gitignore` 中排除，不会随未来仓库提交。
