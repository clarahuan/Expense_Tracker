连接你的云端账本

先保存连接信息，再发送登录邮件。仅使用公开连接信息，绝不填写管理密钥。

复制 Data API 的 /rest/v1/ 地址也可以，保存时会自动转换为项目地址。

首次发送邮件前：设置返回网址

在 Supabase 的 Authentication → URL Configuration 中，将 Site URL 设置为 https://clarahuan.github.io/Expense_Tracker/，Redirect URLs 添加 https://clarahuan.github.io/Expense_Tracker/**。本机调试另加 http://localhost:8000/**。建议直接在公网网站配置和登录。

使用默认邮件模板即可：打开邮件，点击 Sign in 返回网站完成登录，无需修改 SMTP。

邮件中提供的是验证码？

登录使用账号专属本地账本。未登录账本不会自动上传；请先导出 JSON，再在登录后确认恢复。
